# 🛒 MINI E-COMMERCE MERN APPLICATION

A full-stack Mini E-Commerce web application built using the MERN Stack (MongoDB, Express.js, React.js, Node.js).
This project allows users to browse products, search items, view product details, manage cart functionality, and place orders with a responsive and modern UI.

---

# 🚀 Features

## 👤 User Features

* 🏠 Home page with product listings
* 🔍 Product search functionality
* 📄 Product detail page
* 🛒 Add products to cart
* ❌ Remove items from cart
* 💰 Cart total calculation
* 🔔 Toast notifications

---

# 🔌 API Routes

## Product Routes

| Method | Endpoint            | Description        |
| ------ | ------------------- | ------------------ |
| GET    | /api/v1/products    | Get all products   |
| GET    | /api/v1/product/:id | Get single product |

---

## Order Routes

| Method | Endpoint          | Description      |
| ------ | ----------------- | ---------------- |
| POST   | /api/v1/order/new | Create new order |
